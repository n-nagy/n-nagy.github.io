Infrastructure Cost (Monthly)

Base Assumptions
  • Queries align well across all three systems
  • Streaming from Kafka for fresh, low-latency data
  • ClickHouse and Redshift costs modeled at medium-heavy workloads
Postgres (Flattened)
$0 extra
+ $750/mo for read replica (optional). Best if current db.r5.2xlarge infra can absorb the reporting load.
ClickHouse
$1,200–$1,500
Self-hosted on r6a.8xlarge. $2,000–$2,500 on ClickHouse Cloud. Pay-per-use pricing scales smoothly; Cloud option saves operational overhead.
Redshift (ra3.xlplus)
$1,700–$2,200
For 2–3 nodes + ~$400 for AWS Glue/Kinesis ETL (optional). Could reach $7K/month if scaled. More expensive per-core and for usage spikes.
